# 森林图

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 比较不同变量、模型、条件或组的点估计及区间，不以区间是否跨零替代未给出的统计检验 |
| 输入结构 | 每行的标签、点估计、区间下限/上限、真实单位，以及可选的已有 p/显著性标签；区间类型和置信水平须明确 |
| 画布与字体 | 普通轴高 40.64 mm，密集多行图可增加高度；Arial 9 pt 常规字重，不以缩小字号容纳更多行 |
| 坐标与排序 | 横轴为估计量及真实单位，纵向行序保持输入的变量/模型层级；数值范围覆盖所有区间，比较面板使用协调范围 |
| 主体图层 | 点直径通常 3 pt；水平区间线 0.75 pt，端帽 2 pt；同一条件沿用相同颜色 |
| 零参考线 | 指标的有意义参考点通常为 0，用灰 #8c8c8c、0.6 pt 点线；指标若以其他值为参考，应由输入明确 |
| 标签与图例 | 变量/模型标签在轴内，与所在行对齐；留足文字宽度，不裁切长标签；需要的图例轴内、9 pt、无框 |
| 误差表达 | 保留已提供的 CI/区间定义和真实上下限，不转换成 SEM，不把非对称区间改成对称误差 |
| 显著性 | 使用既定真实检验结果的“星号/ns, 斜体P=数值”，置于轴内对应行；可估计区间与检验结果分别保留，不凭外观新增统计 |
| 缺失与排除 | 不可估计项保留对应行位置，省略点/区间并按输入状态说明；缺失不能以点估计 0 或 ns 替代 |
| 验收 | 点、区间、标签、星号按行准确对齐，端帽清楚，区间未截断，负值和参考线可见，文字均在指定位置 |

具体函数调用及物理尺寸检查见 [Matplotlib 使用说明](matplotlib.md)。
