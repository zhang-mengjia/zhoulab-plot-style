# 柱状图

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 比较离散条件、组别或等级的均值；需要时展示同一动物的条件变化 |
| 输入结构 | 原始/动物汇总值含独立单位 ID、条件、数值及纳入状态；已有汇总表含条件、均值和已计算误差。分组柱另有组别/上层类别字段 |
| 画布与字体 | 每个数据轴高 40.64 mm；Arial 9 pt 常规字重。轴宽由柱数、分组和实际 x 跨度计算，长轴标签增加外边距；轴内标注可增加两端空白并按相同物理缩放重算轴宽，柱宽与净距不变 |
| 柱位与间距 | 柱宽约 6.11 mm，普通中心距约 9.16 mm，非零净距约 3.05 mm；同组相贴柱净距 0，组间净距约 3.05 mm。单位坐标宽 0.45、净距 0.225、步长 0.675，每单位映射 0.5343228200371056 inch |
| 坐标与刻度 | 离散标签对齐柱中心；必要时保留多层分组标签。均值柱通常从 0 起，斜率/差值允许负值；可比较面板范围统一，完整覆盖数据与误差 |
| 主体图层 | 条件原色填充，alpha 0.34，同色不透明轮廓0.75 pt；主体在误差/散点下方 |
| 个体数据与编码 | 每只动物的条件均值用同色 ×，12 pt²、0.5 pt。只横向错开，不改 y 值；大量试次点可用 4 pt²、0.3 pt、alpha 0.45，不能混称动物点 |
| 可选个体连线 | 只连接同一动物的重复条件值；灰 #999999、0.5 pt、alpha 0.6–0.65；各列动物行序与横向错开一致，不跨缺失格子连线 |
| 误差表达 | 使用输入指定的 SEM/SD/CI；线与柱同色、0.75 pt，端帽 2 pt。不可估计误差省略，不能记成 0 |
| 显著性与图例 | 常规实际比较用轴内括号及“星号/ns, 斜体P=数值”；模型消融/变量贡献图仅星号/ns，数值P保留原表，不增加纵轴留白压低柱子；括号 0.6 pt、钩 2 pt、数据/文字/层间净距各 1.5 pt，避开所跨全部点和误差上缘；图例轴内、9 pt、无框 |
| 缺失与排除 | 不绘制缺失柱，不补 0；保留类别位置和对应标签。排除状态不能因样式修改而改变 |
| 验收 | 核对柱的实际物理宽度、净距及相贴关系，所有散点/误差/标签/括号与新柱位一致；最高点和轴内标注完整可见，缺失类别没有假零值 |

## 柱位计算

普通 n 柱的中心位置为 `positions = BAR_STEP × np.arange(n)`，其中 `BAR_STEP = 0.675`。由 `bar_panel(positions)` 按实际 x 跨度计算轴宽，保持约 6.11 mm 柱宽和 3.05 mm 净距。

每组 m 根相贴柱、共 G 组时：

- 第 g 组中心：`g × (m × BAR_WIDTH + BAR_GAP)`，g 从 0 到 G−1。
- 组内第 j 根柱偏移：`(j − (m−1)/2) × BAR_WIDTH`，j 从 0 到 m−1。
- 实际柱位为组中心加组内偏移。组内净距为 0，相邻组外缘净距为 `BAR_GAP = 0.225`。

各组柱数不同时，令第一组左边缘为 0；后一组左边缘为前组左边缘加前组柱数 × `BAR_WIDTH` 再加 `BAR_GAP`；组内第 j 根柱中心为本组左边缘加 `(j+0.5) × BAR_WIDTH`。不得为了凑齐组宽而生成缺失柱。

柱位生成后，刻度、动物点、可选连线、误差及显著性使用同一组实际位置。调用与物理尺寸检查见 [Matplotlib 使用说明](matplotlib.md)。
