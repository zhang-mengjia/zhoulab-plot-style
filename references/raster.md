# Raster

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 展示逐试次/逐单元的事件时序与持续区间，保留个体事件结构 |
| 输入结构 | 每个事件含行 ID、时间或起止时间、事件类型；另提供行顺序、时间单位、对齐事件及可选的条件/纳入状态 |
| 画布与字体 | 高度随行数安排，不强制压成 40.64 mm；Arial 9 pt 常规字重。过密时稀疏显示刻度标签，保留全部数据行 |
| 行结构与排序 | 一个实际 Trial/单元对应一行；按输入顺序或已明确的排序排列，不为了排版删行、合并行或重排条件 |
| 坐标与对齐 | 横轴为真实时间，注明对齐事件/单位；与 PETH 上下组合时横轴范围、零点及窗口边界严格一致 |
| 主体图层 | 瞬时事件用短线或已定义点形，持续事件用真实起止区间；使用明确的颜色/形状区分事件，线条通常 0.75 pt |
| 事件与窗口 | 如需零参考线/分析底区，采用灰 #8c8c8c 点线与 #eeeeee 底区，放在事件层下方；只显示输入定义的窗口 |
| 标签与图例 | 行标签使用真实 Trial/单元标识；图例轴内、9 pt、无框，同一事件编码在全部面板一致 |
| 误差与显著性 | 原始事件图默认不画均值误差带或统计星号；仅在输入明确提供额外统计图层时表达，不改动原始事件 |
| 缺失与排除 | 真实缺失行/无记录状态与观测到的“没有事件”区分；保留实际行位置，不伪造事件或填满空行 |
| 禁止改变的科学信息 | 不删试次、不压缩实际时间、不合并事件、不改起止时间；刻度稀疏只改变文字显示 |
| 验收 | 所有输入行和事件均保留，起止时间与零点准确，密集局部仍可读，与配套 PETH 的时间轴完全对齐 |

与事件平均曲线上下组合时，同时读取 [PETH 规范](peth.md)，保持共同时间范围和对齐点。绘图可使用 Matplotlib 的 `eventplot`、`vlines` 或真实持续区间，但事件图层必须满足上表的数据保留与时间编码要求。
