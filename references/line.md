# 普通折线图

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 展示指标随 Session、Block、时间或有序条件变化；区分系列及其误差 |
| 输入结构 | 每个系列、每个实际 x 位置的均值/点估计及可选误差上下限；个体图另含单位 ID，保留完整坐标索引与纳入状态 |
| 画布与字体 | 轴高 40.64 mm；Arial 9 pt 常规字重。每个真实x数值单位占9.0311 mm，两端各留0.25单位；轴宽=(x最大−x最小+0.5)×9.0311 mm。五等级轴宽40.64 mm，十五Session轴宽130.95 mm |
| 坐标与刻度 | 使用真实的数值/有序位置；必要时稀疏显示刻度文字但保留全部点。同一可比较图组使用协调范围，斜率/差值保留负值 |
| 主体图层 | 均值/点估计线 0.75 pt，点直径3 pt；按系列的实际坐标连接相邻有效观测 |
| 个体数据与编码 | 保留条件的颜色、线型和实心/空心点含义；若展示个体轨迹，只连接同一单位的值，不与群体均值混淆 |
| 误差表达 | 使用同色纵向误差线 0.75 pt，端帽 0 pt；非对称 CI 保留真实上下限。普通折线不用 PETH 阴影带 |
| 显著性与图例 | 逐点结果按真实x对齐，采用“星号/ns, 斜体P=数值”，按实际文字边界错层；标签来自既定真实检验；图例轴内、9 pt、无框，不遮挡主要数据 |
| 缺失与排除 | 先对齐到完整 Session/Block/条件坐标，缺失/排除格子为 NaN，线在此断开；不能删除格子后跨越断档连线 |
| 禁止改变的科学信息 | 不为外观重新合并动物/试次，不把 CI 改成 SEM，不插值，不改变 omission probe 或失败 Attempt 等线型含义 |
| 验收 | 坐标与输入索引一致，误差棒没有横杠，缺失位置明确断线，图例与逐点标注在轴内，轴高保持 40.64 mm |

具体函数调用及物理尺寸检查见 [Matplotlib 使用说明](matplotlib.md)。
