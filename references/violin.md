# 小提琴图

与 [SKILL.md](../SKILL.md) 的字体、误差、显著性及导出规则共同使用。用于展示已有分析单位的分布；本规范不指定预测变量、回归模型、比较对象或多重校正 family。

| 规范项 | 要求 |
|---|---|
| 输入结构 | 每行含单位身份、类别、数值和纳入状态；分组时另有上层规则/条件。可附已有模型边际均值及区间、已计算检验结果 |
| 统计单位 | 保留输入定义。例如 β 图每点为一个动物×Session 的 β；不得为了画小提琴将多个 Session 合成一个动物点，或把 Trial 当作独立动物 |
| 画布与字体 | Arial 9 pt、数据轴高40.64 mm；默认与对应柱图共用类别位置、x范围、物理缩放及数据轴宽高比。长刻度或负值刻度增加外边距，不拉宽或压缩数据轴 |
| 类别位置 | 无上层分组时，类别中心距约9.16 mm；有上层分组时，组内紧邻、组间留距，沿用相贴分组柱的柱位。两类别成对时，组内中心距约6.11 mm，跨组相邻中心距约9.16 mm |
| 密度宽度 | 最大完整宽度等于柱宽，约6.11 mm；半宽约3.05 mm。各类别分别将 KDE 峰值归一到同一最大半宽，不用样本量改变宽度 |
| KDE | 使用原始输入数值上的 Gaussian KDE、Scott 带宽；在该类别有限观测的最小值至最大值之间取200点。不外推密度尾部，不另做变换、截尾或插补 |
| 密度图层 | 保留条件原色，填充alpha=0.34；左右轮廓同色、0.75 pt、不透明，不额外画中位数或四分位线 |
| 个体散点 | 6 pt²、alpha=0.8，保留原点形及配色；只横向抖动，落在该y值的密度宽度85%以内。使用固定随机种子，原始y值与身份对应不变 |
| 均值与误差 | 已有模型边际均值用4 pt白心圆、深灰边/误差线，线宽0.75 pt、端帽2 pt。通常显示既定逐项95% CI；若输入指定其他误差，保留其定义。不从点云另算一个均值替代模型均值，不临时增加模型或检验 |
| 坐标与分组文字 | 刻度对齐实际类别中心，上层规则居中列在其下方；例如PBS、IA下方再标规则名。β图纵轴可仅写β；斜率/差值保留负值，零参考线为灰色虚线0.6 pt |
| 显著性 | 只读取已指定比较及其原始/校正P。轴内括号显示星号/ns及斜体数值P，拥挤时换成两行。括号避开所跨密度、个体点和CI上缘；不因画小提琴额外添加各组对零检验 |
| 缺失/退化 | 保留缺失类别位置，不补零；n<2或数值恒定时不拟造KDE，保留真实点及可估计的已有均值/区间。不可估计结果不标ns |
| 验收 | 核对与柱图一致的数据轴宽高、类别中心和最大完整宽度；组内确实比组间更近；点的y值、数量及模型均值/CI与来源一致；所有文字、括号和数据完整可见 |

## 与柱图共享几何

使用包内 [matplotlib_helpers.py](../scripts/matplotlib_helpers.py) 的 `violin_panel(positions)`，其几何与 `bar_panel(positions)` 相同：

- 坐标完整宽度为 `VIOLIN_WIDTH = BAR_WIDTH = 0.45`，非零间隙为 `BAR_GAP = 0.225`；每个x坐标单位为 `X_UNIT_IN = 0.5343228200371056 inch`。
- 无上层分组时，`positions = BAR_STEP * np.arange(n)`，`BAR_STEP = 0.675`。
- 有上层分组时，按 [分组柱位公式](bar.md#柱位计算) 生成一次 positions，柱图、小提琴、散点、均值/区间和显著性全部共用。
- 标准x范围为 `(min(positions)-0.6, max(positions)+0.6)`；轴宽为x跨度乘以 `X_UNIT_IN`，轴高为1.60 inch。为标注增加两端空白时，同步更新对应柱图与小提琴的范围，并按同一物理缩放重算轴宽。

例如，两条规则各含PBS、IA时，按“规则A-PBS、规则A-IA、规则B-PBS、规则B-IA”排序，`positions = [0, 0.45, 1.125, 1.575]`。标准x范围为 `(-0.6, 2.175)`，两类图的数据轴均约 **37.66×40.64 mm**。这个宽度是该四类别示例的计算结果；类别数或分组结构变化时重新计算，不固定所有小提琴图为四类别宽度。

`draw_violin(ax, position, values, color, mean=estimate, ci=(lower, upper), seed=seed)` 只绘制传入数值及已有均值/区间；不传mean/ci时只画分布和点。将真实检验传给 `add_comparison_brackets`，其 `envelope_by_x` 包含所有有限个体值及CI上缘。导出使用包内统一裁切；比对的是数据轴尺寸，外部画布可以因刻度文字长度而不同。
