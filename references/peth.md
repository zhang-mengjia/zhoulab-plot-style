# PSTH / PETH / 事件动态图

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 展示相对于一个明确事件的时间动态，可比较条件、动物或 Block |
| 输入结构 | 时间 bin 中心或明确的时间坐标、每个条件/单位的均值曲线及误差/上下限；同时提供对齐事件、显示窗、bin 宽、平滑/基线/归一化设置和独立统计单位 |
| 画布与字体 | 每个数据轴高 40.64 mm；Arial 9 pt 常规字重。普通 PETH 默认数据轴宽约54.92 mm；PSTH 轴宽按下述统一时间尺度计算。保留既定时间窗；标签增加外边距 |
| 多面板结构 | 分 Block 时，一个 Block 一个面板，叠加该 Block 实际存在的条件；对应面板统一时间轴、可比较的纵轴范围及颜色 |
| 坐标与单位 | 普通 PETH 横轴写明“Time from 对齐事件 (s)”；PSTH 横轴使用下述每秒数字刻度和事件名称。纵轴使用真实 Occupancy (%)、Entry intensity (s⁻¹)、firing rate (Hz) 或 z score，不混用指标或归一化 |
| 主体图层 | 连续均值线 0.75 pt；默认不为每个 bin 加点或误差棒，不自动平滑输入 |
| 误差表达 | 同色阴影带，alpha 0.18、无边线；采用输入定义的 SEM/CI 和独立单位，支持非对称上下限，不能把试次当成独立动物 |
| 事件与窗口 | t=0 用灰 #8c8c8c、0.55 pt 点线；已定义的 Cue/分析窗用 #eeeeee 灰底区，置于曲线与误差带下方。窗口长度必须来自输入，不固定猜为 10 s |
| 条件编码与图例 | 条件颜色/线型与其他图一致；图例轴内、9 pt、无框，每个条件只显示一次 |
| 显著性 | 风格修改不增加逐 bin 或簇检验。仅当输入已有对应统计结果及比较定义时，按该结果表达且保留轴内可读性 |
| 缺失与排除 | 缺失 bin 的线和带同时断开；均值有效而误差不可估计时保留均值、省略该处带；不存在的 TrialType 不绘制、不补零 |
| 禁止改变的科学信息 | 不擅自改变对齐点、分箱、平滑核/sigma、基线窗、曝光分母、归一化或样本权重 |
| 验收 | 零点、时间范围和底区准确；各条件颜色一致，阴影可读，缺口未被连接；均值和误差的统计单位明确，分 Block 面板可直接比较 |

具体函数调用及物理尺寸检查见 [Matplotlib 使用说明](matplotlib.md)。

## PSTH 的物理尺寸与时间尺度

- 图宽、图高、宽高比和面板尺寸均指数据坐标轴绘图区。每个轴固定高 40.64 mm，外围画布容纳标签、刻度文字、允许的个体标题、图例和安全边距。
- 同一 PSTH 图组的所有事件、条件、单元与日期使用相同的每秒物理宽度。轴宽按 `时间窗跨度 × 每秒物理宽度` 计算，时间窗改变时同步调整轴宽。
- 当前采用 3 s 窗口的数据轴宽高比 3∶4，轴高 40.64 mm，对应轴宽 30.48 mm、时间尺度 10.16 mm/s。12 s 窗口的轴宽为 121.92 mm。
- PSTH 横轴主刻度每 1 s 一个，覆盖显示时间窗中的整数秒。
- 对齐零点和事件标记使用实际事件语义。PSTH 横轴由每秒数字刻度和事件名称构成。`Lever out`、`Lever press`、`Well entry`、`Reward delivery` 均使用单行 Arial 9 pt 常规字体，统一旋转 45°，文字锚点对准横轴上各自事件的时间位置；通过旋转与对齐安排相邻标签。
- 画布、坐标轴与导出背景均为白色；曲线误差带沿用条件同色的 alpha 0.18 填充。
- 使用各时间 bin 的中心作为曲线横坐标，保留真实时间间隔。图组的纵轴范围覆盖全部条件及误差。

## 当前 DVC 单步 PSTH 预设

该预设用于用户当前的 DVC 单步任务；其他任务依据其已确认的事件和参数绘制。

| 面板 | 对齐零点 | 显示时间窗 | 数据轴宽 × 高 |
|---|---|---|---|
| Lever out | 伸杆 | −1～＋2 s | 30.48 × 40.64 mm |
| Lever press | 伸杆后第一次有效按压 | −1～＋2 s | 30.48 × 40.64 mm |
| Well entry 与 Reward delivery 连续面板 | Well entry | −1～＋11 s | 121.92 × 40.64 mm |

- 连续面板在横轴 0 s 处放置 `Well entry`，在＋1 s 处放置 `Reward delivery`，并保留每秒的数字刻度。该＋1 s 标记对应本任务已确认的给水延迟；曲线以实际 Well entry 时间对齐。
- 当前分箱为 50 ms，高斯平滑 σ 为 100 ms，以秒指定 σ 并换算到 bin。两端各扩展 4σ，即 400 ms，逐 trial 平滑后裁回显示窗。
- 各 trial 的 bin 计数除以 bin 宽得到 Hz，再按既定条件计算均值与误差。试次筛选、分组和误差的独立单位沿用任务输入。
- 验收时检查每个数据轴的实际宽高，并核对 `轴宽 / 时间窗跨度` 在所有面板与输出中一致。
