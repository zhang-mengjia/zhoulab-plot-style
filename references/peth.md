# PETH / 事件动态图

与 [SKILL.md](../SKILL.md) 中的通用物理规格、配色、误差及导出规则共同使用。下表分别规定输入、画布与坐标、数据图层、误差与标注、缺失处理及验收；输入字段可映射到实际列名，不要求改动原始数据表。

| 规范项 | 要求 |
|---|---|
| 适用目的 | 展示相对于一个明确事件的时间动态，可比较条件、动物或 Block |
| 输入结构 | 时间 bin 中心或明确的时间坐标、每个条件/单位的均值曲线及误差/上下限；同时提供对齐事件、显示窗、bin 宽、平滑/基线/归一化设置和独立统计单位 |
| 画布与字体 | 每个数据轴高 40.64 mm；Arial 9 pt 常规字重，默认数据轴宽约54.92 mm，保留既定时间窗；标签增加外边距 |
| 多面板结构 | 分 Block 时，一个 Block 一个面板，叠加该 Block 实际存在的条件；对应面板统一时间轴、可比较的纵轴范围及颜色 |
| 坐标与单位 | 横轴写明“Time from 对齐事件 (s)”；纵轴使用真实 Occupancy (%)、Entry intensity (s⁻¹)、firing rate (Hz) 或 z score，不混用指标或归一化 |
| 主体图层 | 连续均值线 0.75 pt；默认不为每个 bin 加点或误差棒，不自动平滑输入 |
| 误差表达 | 同色阴影带，alpha 0.18、无边线；采用输入定义的 SEM/CI 和独立单位，支持非对称上下限，不能把试次当成独立动物 |
| 事件与窗口 | t=0 用灰 #8c8c8c、0.55 pt 点线；已定义的 Cue/分析窗用 #eeeeee 灰底区，置于曲线与误差带下方。窗口长度必须来自输入，不固定猜为 10 s |
| 条件编码与图例 | 条件颜色/线型与其他图一致；图例轴内、9 pt、无框，每个条件只显示一次 |
| 显著性 | 风格修改不增加逐 bin 或簇检验。仅当输入已有对应统计结果及比较定义时，按该结果表达且保留轴内可读性 |
| 缺失与排除 | 缺失 bin 的线和带同时断开；均值有效而误差不可估计时保留均值、省略该处带；不存在的 TrialType 不绘制、不补零 |
| 禁止改变的科学信息 | 不擅自改变对齐点、分箱、平滑核/sigma、基线窗、曝光分母、归一化或样本权重 |
| 验收 | 零点、时间范围和底区准确；各条件颜色一致，阴影可读，缺口未被连接；均值和误差的统计单位明确，分 Block 面板可直接比较 |

具体函数调用及物理尺寸检查见 [Matplotlib 使用说明](matplotlib.md)。
